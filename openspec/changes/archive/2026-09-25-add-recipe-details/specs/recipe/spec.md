## ADDED Requirements

### Requirement: S03 レシピ詳細ドロワーの表示

システムは、レシピ 1 件の内容を読むための S03 レシピ詳細ドロワーを SHALL 提供する。
ドロワーは画面右から開き、幅は画面の 40〜50% とする。開いている間、背後の画面は見えたまま暗く表示される。
ドロワーには次の項目をこの順で表示する。

- 基本情報：レシピ名、タグ、人数 (「N 人分」)、更新日
- 材料：1 行 1 材料で、名前と量と単位。量が 0 の材料は量を出さず、名前と単位だけを出す
- 手順
- メモ
- 「編集」ボタン

材料が 0 件、手順が空、メモが空の場合は、その欄に「未登録」である旨を表示し、欄そのものは省略しない。
「削除」ボタンは表示しない。

#### Scenario: 詳細ドロワーに基本情報と材料と手順とメモが表示される

- **GIVEN** レシピ「肉じゃが」(タグ「和食」、人数 2、材料「玉ねぎ 1 個」、手順とメモあり) が登録されている
- **WHEN** ユーザーが「肉じゃが」の S03 詳細ドロワーを開く
- **THEN** ドロワーに「肉じゃが」「和食」「2 人分」と更新日が表示される
- **AND** 材料欄に「玉ねぎ 1 個」が表示される
- **AND** 手順欄とメモ欄に登録した内容が表示される
- **AND** 「編集」ボタンが表示され、「削除」ボタンは表示されない

#### Scenario: 空の欄には未登録である旨が表示される

- **GIVEN** 名前だけを入力して保存したレシピ「豚汁」が登録されている
- **WHEN** ユーザーが「豚汁」の S03 詳細ドロワーを開く
- **THEN** 材料欄、手順欄、メモ欄のそれぞれに「未登録」である旨が表示される

#### Scenario: 量が 0 の材料は量を出さずに表示される

- **GIVEN** レシピに材料「塩」(量 0、単位「少々」) が登録されている
- **WHEN** ユーザーがそのレシピの S03 詳細ドロワーを開く
- **THEN** 材料欄に「塩 少々」が表示され、「0」は表示されない

#### Scenario: レシピを読み込めない場合はエラーを表示する

- **GIVEN** ドロワーを開こうとしたレシピが、読み込みの時点で存在しない
- **WHEN** S03 詳細ドロワーが開く
- **THEN** ドロワー内に「レシピを読み込めない」旨のメッセージが表示され、ドロワーは閉じる操作を受け付ける

### Requirement: S03 の開閉

システムは、S03 詳細ドロワーを閉じる操作として、`×` ボタン、ドロワー外の背景のクリック、Esc キーの 3 つを SHALL 受け付ける。
閉じたあとは、ドロワーを開く前の画面がそのままの状態で表示される。

#### Scenario: `×` ボタンで閉じる

- **GIVEN** S03 詳細ドロワーが開いている
- **WHEN** ユーザーが `×` ボタンを押す
- **THEN** ドロワーが閉じ、開く前の画面だけが表示される

#### Scenario: 背景クリックで閉じる

- **GIVEN** S03 詳細ドロワーが開いている
- **WHEN** ユーザーがドロワー外の背景をクリックする
- **THEN** ドロワーが閉じ、開く前の画面だけが表示される

#### Scenario: Esc キーで閉じる

- **GIVEN** S03 詳細ドロワーが開いている
- **WHEN** ユーザーが Esc キーを押す
- **THEN** ドロワーが閉じ、開く前の画面だけが表示される

### Requirement: S02 一覧から S03 を開く

システムは、S02 レシピ一覧の各行を押下したとき、そのレシピの S03 詳細ドロワーを S02 の上に SHALL 開く。
S02 はドロワーの左側に見えたまま残る。ドロワーを閉じたとき、S02 の検索語と並び順は開く前の状態が保たれる。

#### Scenario: 行を押すと S03 詳細ドロワーが開く

- **GIVEN** レシピ「肉じゃが」が S02 レシピ一覧に表示されている
- **WHEN** ユーザーが「肉じゃが」の行を押下する
- **THEN** 「肉じゃが」の S03 詳細ドロワーが右から開く
- **AND** S02 の一覧はドロワーの左側に見えている
- **AND** S04 編集画面には遷移しない

#### Scenario: 閉じると検索語と並び順が保たれている

- **GIVEN** ユーザーが S02 で検索欄に「じゃが」と入力し、並び順を「名前 昇順」にしている
- **AND** 絞り込まれた行から S03 詳細ドロワーを開いている
- **WHEN** ユーザーがドロワーを閉じる
- **THEN** 検索欄には「じゃが」が残り、並び順は「名前 昇順」のままである

### Requirement: S03 から S04 編集画面への遷移

システムは、S03 詳細ドロワーの「編集」ボタンが押されたとき、そのレシピの S04 編集画面へ SHALL 遷移する。
S04 で保存した場合は S02 レシピ一覧に戻り、保存したレシピの行を強調表示する。
S04 でキャンセルした場合 (未保存の変更を破棄した場合を含む) は、そのレシピの S03 詳細ドロワーを開いた S02 に戻る。
S03 をどの画面から開いていたかにかかわらず、S04 からの戻り先はこの規則に従う。

#### Scenario: 編集を押すと既存値がロードされた S04 に遷移する

- **GIVEN** レシピ「肉じゃが」の S03 詳細ドロワーが開いている
- **WHEN** ユーザーが「編集」を押す
- **THEN** 画面が S04 レシピ編集画面に遷移し、「肉じゃが」の既存値がロードされている

#### Scenario: 保存すると S02 に戻り行が強調される

- **GIVEN** ユーザーが S03 から「肉じゃが」の S04 編集画面に入っている
- **WHEN** ユーザーが人数を「3」に変更して「保存」を押す
- **THEN** 画面は S02 レシピ一覧に戻り、ドロワーは開いていない
- **AND** 「肉じゃが」の行が強調表示される

#### Scenario: キャンセルすると S03 に戻る

- **GIVEN** ユーザーが S03 から「肉じゃが」の S04 編集画面に入り、何も変更していない
- **WHEN** ユーザーが「キャンセル」を押す
- **THEN** 画面は S02 に戻り、「肉じゃが」の S03 詳細ドロワーが開いている

#### Scenario: 保存した内容が S03 に反映される

- **GIVEN** ユーザーが「肉じゃが」の人数を「3」に変更して保存し、S02 に戻っている
- **WHEN** ユーザーが「肉じゃが」の行を押して S03 詳細ドロワーを開く
- **THEN** ドロワーに「3 人分」が表示される

### Requirement: S01 献立カレンダーから S03 を開く

システムは、S01 献立カレンダーの品行メニュー「この品のレシピ詳細を見る」が選ばれたとき、その品のレシピの S03 詳細ドロワーを
S01 の上に SHALL 開く。ドロワーを閉じたとき、画面は S02 を経由せず S01 に留まり、表示期間と表示中の時間帯は開く前のまま保たれる。

#### Scenario: S01 から開いて閉じると S01 に留まる

- **GIVEN** S01 の「金曜・夕」に「肉じゃが」が割り当てられている
- **WHEN** ユーザーが「肉じゃが」の品行メニューから「この品のレシピ詳細を見る」を選ぶ
- **THEN** 「肉じゃが」の S03 詳細ドロワーが S01 の上に開く
- **WHEN** ユーザーがドロワーを閉じる
- **THEN** 画面は S01 のままで、表示期間は開く前と同じである

### Requirement: 手順とメモの Markdown 描画

システムは、S03 詳細ドロワーの手順欄とメモ欄で、保存されたテキストを Markdown として SHALL 描画する。
描画の対象は、見出し、段落、改行、箇条書き、番号付きリスト、強調 (太字 / 斜体)、インラインコード、コードブロック、引用とする。
アプリは外部と通信しないため、次の 2 つは描画せずに置き換える。

- 画像記法：画像を読み込まず、代替テキストだけを表示する
- リンク記法：リンクとして振る舞わず、リンクテキストを通常の文字列として表示する (押しても画面は遷移しない)

HTML タグを含むテキストは、タグとして解釈せず文字列として扱う。

#### Scenario: 見出しと箇条書きが描画される

- **GIVEN** レシピの手順に `## 下ごしらえ\n- 玉ねぎを切る\n- 豚肉を漬ける` が保存されている
- **WHEN** ユーザーがそのレシピの S03 詳細ドロワーを開く
- **THEN** 手順欄に「下ごしらえ」が見出しとして表示され、「##」の記号は表示されない
- **AND** 「玉ねぎを切る」「豚肉を漬ける」が箇条書きとして表示される

#### Scenario: 画像記法は代替テキストだけが表示される

- **GIVEN** レシピのメモに `![完成写真](https://example.com/a.jpg)` が保存されている
- **WHEN** ユーザーがそのレシピの S03 詳細ドロワーを開く
- **THEN** メモ欄に「完成写真」の文字列が表示され、画像は読み込まれない

#### Scenario: リンク記法は遷移しない文字列として表示される

- **GIVEN** レシピのメモに `[参考](https://example.com)` が保存されている
- **WHEN** ユーザーがそのレシピの S03 詳細ドロワーを開き、「参考」の文字列を押す
- **THEN** 画面は遷移せず、ドロワーは開いたままである

#### Scenario: HTML タグは文字列として表示される

- **GIVEN** レシピのメモに `<b>強火</b>` が保存されている
- **WHEN** ユーザーがそのレシピの S03 詳細ドロワーを開く
- **THEN** メモ欄は「強火」を太字にせず、タグを含む文字列として扱う

## MODIFIED Requirements

### Requirement: 未保存変更のキャンセル確認

システムは、S04 レシピ登録/編集画面で入力内容が初期値から変更されている (dirty である) 状態で「キャンセル」が押された場合、
変更を破棄するかを問う確認ダイアログを SHALL 表示する。dirty でない場合は確認なしで呼び出し元に戻る。
呼び出し元は、新規登録モードでは S02 レシピ一覧、編集モードではそのレシピの S03 詳細ドロワーを開いた S02 とする。

#### Scenario: dirty 状態でキャンセルを押すと確認される

- **GIVEN** ユーザーが S04 新規登録画面で名前欄に文字を入力した状態
- **WHEN** ユーザーが「キャンセル」を押す
- **THEN** 「未保存の変更を破棄しますか」旨の確認ダイアログが表示される
- **WHEN** ユーザーが「破棄」を選ぶ
- **THEN** 画面は呼び出し元 (S02) に戻り、入力内容は保存されていない

#### Scenario: dirty でない状態のキャンセルは確認をスキップする

- **GIVEN** ユーザーが S04 新規登録画面を開き、まだ何も入力していない
- **WHEN** ユーザーが「キャンセル」を押す
- **THEN** 確認ダイアログは表示されず、画面は呼び出し元 (S02) に戻る

#### Scenario: 確認ダイアログで「編集を続ける」を選ぶと画面に留まる

- **GIVEN** dirty 状態で「キャンセル」を押し、確認ダイアログが表示されている
- **WHEN** ユーザーが「編集を続ける」を選ぶ
- **THEN** ダイアログが閉じ、S04 の入力内容はそのまま保持される

#### Scenario: 編集モードで変更を破棄すると S03 に戻る

- **GIVEN** ユーザーが「肉じゃが」の S04 編集画面で人数を変更した状態
- **WHEN** ユーザーが「キャンセル」を押し、確認ダイアログで「破棄」を選ぶ
- **THEN** 画面は S02 に戻り、「肉じゃが」の S03 詳細ドロワーが開いている
- **AND** ドロワーに表示される人数は変更前のままである

### Requirement: 手順とメモの Markdown 記法対応

システムは、S04 レシピ登録/編集画面の手順欄とメモ欄で、Markdown 記法のテキストをそのまま受け付けて保存することを SHALL 保証する。
書き手側 (S04) ではプレーンテキスト入力として振る舞い、Markdown レンダリングは行わない。読み手側の描画は
S03 詳細ドロワーで行う (「手順とメモの Markdown 描画」要件)。手順欄には Markdown 記法が使える旨のヒントを表示する。

#### Scenario: Markdown 記法のテキストが素通しで保存・再表示される

- **GIVEN** ユーザーが S04 編集画面で手順欄に `## 下ごしらえ\n- 玉ねぎを切る\n- 豚肉を漬ける` を入力し、「保存」を押した
- **WHEN** 同じレシピを再度 S04 編集画面で開く
- **THEN** 手順欄に入力した Markdown テキストが変換されず、そのままの文字列で表示される

#### Scenario: 手順欄には Markdown が使える旨のヒントが表示される

- **WHEN** ユーザーが S04 新規登録画面を開く
- **THEN** 手順欄の近くに「Markdown 記法で書けます」旨のヒントが表示されている

## REMOVED Requirements

### Requirement: S02 一覧からのレシピ編集導線 (暫定)

**Reason**: S03 レシピ詳細ドロワーが入ったため、暫定の「行押下 → S04」導線は役目を終えた。
**Migration**: 行押下は「S02 一覧から S03 を開く」要件でドロワーを開き、編集は「S03 から S04 編集画面への遷移」要件の
「編集」ボタンから行う。
