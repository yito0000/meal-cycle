## Why

S01 の品行では、レシピ名に残る幅がほとんど無い。
1920×1080 の画面 (拡大率 100%、アプリ内の CSS 幅 1088px) で実測すると、1 セルの幅 94px のうちレシピ名に残るのは 23px で、1 文字しか読めない。
作り置きで作った印も付いた品では、名前の左に 🔗 とチェックが並び、名前の幅は 0 になる。
拡大率 125% (CSS 幅 870px) では、どの品も名前が読めない。

幅を使っているのは、セルの内側の余白、品行の右端の `⋯`、名前の左の 🔗 と作った印である。
2 週と 4 週の表示も 7 列ごとに折り返すので、列幅はどの期間でも同じであり、表示期間を変えても解決しない。

あわせて、`add-mealplan-cooked-mark` で入れた作った印は、`⋯` から選ぶ 2 クリックの操作になっている。
調理した日にいちばん頻繁に使う操作なので、印そのものを押して付け外しできるほうが直感的である。

## What Changes

- 品行の右端の `⋯` をやめ、品行 (レシピ名) をクリックすると品のメニューが開くようにする
  - メニューは品行の右に開き、画面の端で収まらないときは左に開く
  - 品行をドラッグしたときはメニューを開かず、これまでどおり D&D として扱う
  - キーボードでは、品行にフォーカスを当てて Enter または Space で開く
- 品行の左端に、作った印のチェックボックスを常に表示する。1 クリックで印を付け外しする
  - 品のメニューから「作った」「作った印を外す」の項目を外す
- 品行の 🔗 をやめ、作り置きは枠の色だけで見分ける
- レシピ名を 1 行で省略せず、2 行まで折り返す。3 行目以降は省略する。すべての表示期間と時間帯数で同じにする
- セルの内側の余白、品行の左右の余白、時間帯ラベルの列幅を詰める

この変更で、1088px の画面ではレシピ名がおよそ 3〜4 字×2 行まで読めるようになる (試作での実測から見積もった値)。
作り置きで作った印の付いた品も、単独の品と同じ幅になる。

### Non-goals

- **サイドバーの折りたたみ**：サイドバー (234px) は全画面のシェルの変更になるので、この proposal に含めない。
  870px の画面では、この proposal を入れても名前はおよそ 2 字×2 行にとどまる
- **ルートの文字サイズと Wails の Zoom の見直し**：`html { font-size: 18px }` と Zoom 1.5 の重なりが幅を削る根本の原因だが、
  全画面の見た目に関わるので扱わない
- **表示期間の追加 (3〜4 日表示) や横スクロール**：週単位で献立を見渡す使い方を保つため、7 列の並べ方は変えない
- **S07 の献立欄の 🔗**：S07 の「この期間の献立」欄は幅に余裕があるので、🔗 を残す
- **時間帯全体の `⋯` メニュー**：セル右下の時間帯の `⋯` は変えない
- **「他 N 件」に畳まれた品の操作**：セルの表示件数の仕組みは変えない

### Modified Capabilities

- `mealplan`：
  - 「セル内の品表示」：品行の `⋯` をやめ、品行のクリックで品のメニューを開く。チェックボックスと 2 行の折り返しを足す
  - 「1 品の入替 / 削除 / 詳細表示」「事後編集による作り置きの外し / まとめ」「作り置きを広げる (統合ダイアログ)」：
    `⋯` から選ぶ操作を、品のメニューから選ぶ操作に書き換える
  - 「作り置きの意味付け」：単独の作り置きに 🔗 が出ない旨の記述を、枠の色だけの記述に改める
  - 「作り置きの視覚識別」を REMOVED にし、新しい要件「作り置きの枠色による識別」を ADDED で足す。
    既存のシナリオ「🔗 アイコンで複数行の作り置きを識別する」を残せないため、要件ごと置き換える
  - 「1 行 移動 (ドラッグ&ドロップ)」：品行のクリックとドラッグの区別、カーソルの表示を改める
  - 「作った印」：付け外しの操作を、品のメニューの項目からチェックボックスに変える
  - 「作り置きの編集と作った印」：`⋯` から選ぶ操作を、品のメニューから選ぶ操作に書き換える
- `shopping`：
  - 「期間の献立一覧」：🔗 を「S01 と同じ作り置きの印」と呼んでいる記述を改める (S07 の表示は変えない)
