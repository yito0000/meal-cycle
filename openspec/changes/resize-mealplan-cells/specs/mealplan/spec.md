## MODIFIED Requirements

### Requirement: セル内の品表示

システムは、各 (日付, meal) セル内に、その時間帯に割り当てられた品を **position 昇順** で縦積み表示 SHALL する。
0 品の時間帯 は空セルとして表示し、1..N 品はレシピ名を 1 行 1 品で描画する。各品行にはその品に対する `⋯` メニュー
(入れ替え / 削除 / 詳細 / 連続 N 日) を、時間帯右下には 時間帯全体の `⋯` メニュー (全クリア / 全体連続 N 日 /
並び替え) を配置する。

セル高さ、レシピ名の文字サイズ、およびセル内で折り畳まずに見せる品数の上限 (「他 N 件」表示の閾値) は、
**表示期間 (1 週 / 2 週 / 4 週)** と **表示時間帯数 (1〜3)** の組み合わせに応じて可変となる。目安として、
表示密度が低い組み合わせ (期間が短く 時間帯数が少ない) ほどセルは縦に大きく、レシピ名は視認性の良い大きさで
描画され、より多くの品を折り畳まずに見せる。逆に表示密度が高い組み合わせ (期間 4 週) では、より多くの日付を
一望できるようセルは小さく、レシピ名も控えめな大きさになる。

#### Scenario: 0 品の時間帯 は空セルになる

- **WHEN** ある (日付, meal) に紐づく品が 1 つも無い
- **THEN** そのセルは空セルとして表示される (レシピ名の描画は無い)
- **AND** 空セル中央の `＋` ボタンが表示される

#### Scenario: 複数品は position 順に縦積みされる

- **WHEN** ある (日付, meal) に position=0 の「肉じゃが」と position=1 の「みそ汁」が紐づいている
- **THEN** そのセル内に「肉じゃが」「みそ汁」の順で 2 行が縦に並んで表示される
- **AND** 各行の右端に品単位の `⋯` メニューが表示される

#### Scenario: 品数超過は省略表示になる

- **WHEN** ある (日付, meal) の品数が、その表示状態 (期間 × 時間帯数) で決まる「セル内表示上限」を超える
- **THEN** そのセルには先頭の上限件数までの品が表示される
- **AND** その後ろに「他 N 件」の省略行が 1 行表示される

#### Scenario: 割当済セルには右上に `＋`、右下に時間帯 `⋯` が並ぶ

- **WHEN** ある (日付, meal) に 1 品以上が紐づいている
- **THEN** セル右上に品追加用の `＋` が、セル右下に 時間帯全体用の `⋯` メニューが表示される

#### Scenario: 1 週 × 夕食のみのセルは 3 品以上を折り畳まずに表示できる

- **WHEN** ユーザーが S01 を既定 (1 週 × 夕食のみ) で開き、ある (日付, meal) に 3 品が紐づいている
- **THEN** そのセルには 3 品すべてが折り畳まれずに縦積み表示される (「他 N 件」の省略行は出ない)

#### Scenario: 表示密度が上がるとセル内表示上限が下がる

- **WHEN** ある (日付, meal) に 3 品が紐づいた状態で、ユーザーが期間切替を「1 週」から「4 週」に変更する
- **THEN** そのセルの品表示は、先頭の少数 (少なくとも 3 品より少ない件数) だけになり、超過分は
  「他 N 件」の省略行に集約される
