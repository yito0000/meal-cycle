## ADDED Requirements

### Requirement: データの書き出し

システムは、S09 の最後に「データ」の節を SHALL 表示し、その中に「データを書き出す」を置く。
「データを書き出す」を押すと OS の保存ダイアログを開き、選んだ場所に、献立、レシピ、在庫、常備品、設定を含むデータ全体を 1 つのファイルで書き出す。
既定のファイル名は `meal-cycle-` に書き出した日時 (`YYYYMMDD-HHMMSS`) と `.db` を続けたものとする。
書き出したら、書き出した場所を通知で知らせる。保存ダイアログを閉じたときは何もしない。
書き出せなかったときは失敗を通知で知らせ、書きかけのファイルを残さない。
書き出したファイルは、「復元する」の「ファイルを選ぶ」で選べる。

#### Scenario: データを 1 つのファイルに書き出す

- **GIVEN** 献立に「肉じゃが」が割り当てられ、在庫に「玉ねぎ 3 個」がある
- **WHEN** ユーザーが S09 の「データを書き出す」を押し、保存ダイアログで場所を選ぶ
- **THEN** 選んだ場所に `meal-cycle-` で始まる `.db` のファイルが作られ、その場所が通知で表示される

#### Scenario: 保存ダイアログを閉じると何もしない

- **WHEN** ユーザーが S09 の「データを書き出す」を押し、保存ダイアログを閉じる
- **THEN** ファイルは作られず、通知も表示されない

### Requirement: 復元の予約

システムは、S09 のデータの節に「復元する」を SHALL 置き、押すと復元に使うファイルを選ぶダイアログを開く。
ダイアログには、スキーマ更新前の控えと復元前の控えを、作成日時の新しい順に一覧する。各控えには作成日時と、どの操作の前の控えかを表示する。
ダイアログの「ファイルを選ぶ」では、OS のファイル選択ダイアログで任意のデータのファイルを選べる。

控えかファイルを選ぶと、次の起動で復元すること、予約の後に変えた内容は復元で消えること、今のデータは復元の前に控えに残ることを示す確認ダイアログを出す。
確認すると、次の起動で選んだファイルの内容に置き換える予約をする。予約しただけでは今のデータを変えない。

選んだファイルが次のどれかに当たるときは予約せず、理由を表示する。

- meal-cycle のデータのファイルとして開けない、または壊れている
- このアプリより新しい版のアプリで作られたデータである

このアプリより古い版のアプリで作られたデータは予約できる。

#### Scenario: 控えを選んで復元を予約する

- **GIVEN** `backups` フォルダに更新前の控えが 2 つある
- **WHEN** ユーザーが S09 の「復元する」を押す
- **THEN** 2 つの控えが作成日時の新しい順に一覧される
- **WHEN** ユーザーが新しいほうの控えを選び、確認ダイアログで確認する
- **THEN** S09 に、次の起動でその控えから復元する旨が表示される
- **AND** S01 の献立は予約の前と変わらない

#### Scenario: 書き出したファイルを選んで復元を予約する

- **GIVEN** 「データを書き出す」で書き出したファイルがある
- **WHEN** ユーザーが S09 の「復元する」の「ファイルを選ぶ」でそのファイルを選び、確認ダイアログで確認する
- **THEN** S09 に、次の起動でそのファイルから復元する旨が表示される

#### Scenario: データのファイルでないものは予約できない

- **WHEN** ユーザーが「ファイルを選ぶ」で meal-cycle のデータではないファイルを選ぶ
- **THEN** 予約はされず、データのファイルとして開けない旨が表示される

#### Scenario: 新しい版のデータは予約できない

- **WHEN** ユーザーが「ファイルを選ぶ」で、このアプリより新しい版のアプリで作られたデータのファイルを選ぶ
- **THEN** 予約はされず、新しい版のアプリで作られたデータである旨が表示される

### Requirement: 復元の予約の取り消しと終了

システムは、復元を予約している間、S09 のデータの節の先頭に、予約したファイルの名前と、次の起動で復元する旨を SHALL 表示する。
あわせて「予約を取り消す」と「今すぐ終了する」を表示する。
「予約を取り消す」を押すと予約を取り消し、次の起動では復元しない。
「今すぐ終了する」を押すとアプリを終了する。アプリを起動し直すと復元が当たる。
予約している間も、データの書き出しと、別のファイルでの予約はできる。別のファイルで予約すると、前の予約を置き換える。

#### Scenario: 予約を取り消す

- **GIVEN** 控えから復元を予約している
- **WHEN** ユーザーが S09 の「予約を取り消す」を押す
- **THEN** 予約中の表示が消える
- **AND** アプリを起動し直しても、データは予約の前のまま変わらない

#### Scenario: 予約したあとに S09 を開き直しても予約中と表示される

- **GIVEN** 控えから復元を予約している
- **WHEN** ユーザーがサイドバーで S01 を開いてから、S09 を開く
- **THEN** S09 のデータの節に、次の起動でその控えから復元する旨が表示される
