## ADDED Requirements

### Requirement: 期間切替

システムは、S01 の表示期間を **1 週 / 2 週 / 4 週** から切り替えられる UI を画面右上に SHALL 提供する。
既定は 1 週。期間を切り替えても取得起点日 (`periodStart`) は変わらず、表示される日数だけが 7 / 14 / 28 に
広がる。

#### Scenario: 期間切替の既定は 1 週

- **WHEN** ユーザーが S01 を開く
- **THEN** 期間切替 UI の既定選択は「1 週」である
- **AND** カレンダーには 7 日分だけが表示される

#### Scenario: 2 週を選ぶと 14 日分が表示される

- **WHEN** ユーザーが期間切替を「2 週」に変更する
- **THEN** カレンダーには 14 日分の列が表示される
- **AND** 画面幅が足りない場合は横スクロールできる

#### Scenario: 4 週を選ぶと 4 週分が行方向に折り返す

- **WHEN** ユーザーが期間切替を「4 週」に変更する
- **THEN** カレンダーは 4 週分を行方向に折り返して表示する (1 週 = 1 行の反復)

### Requirement: 前後ナビゲーション

システムは、現在の表示期間を前後に移動するナビゲーション UI (`＜` / `＞` / 「今週」) を画面右上に
SHALL 提供する。`＜` / `＞` は現在の期間長 (7 / 14 / 28 日) 分だけ `periodStart` を過去 / 未来に
シフトする。「今週」は `periodStart` を「今日を含む週の月曜日」にリセットする。

#### Scenario: `＞` を押すと表示中の期間長ぶん未来にシフトする

- **WHEN** S01 が「2026-08-24 週 (1 週表示)」を表示している状態でユーザーが `＞` を押す
- **THEN** 表示が「2026-08-31 週」に切り替わる (7 日ぶん未来)

#### Scenario: 2 週表示中の `＞` は 14 日ぶんシフトする

- **WHEN** S01 が「2026-08-24 週 (2 週表示、8/24〜9/6)」を表示している状態でユーザーが `＞` を押す
- **THEN** 表示が「2026-09-07 週 (2 週表示、9/7〜9/20)」に切り替わる

#### Scenario: 「今週」ボタンで現在の週に戻る

- **WHEN** ユーザーが `＞` を何度か押して過去 / 未来の週を表示している状態で「今週」ボタンを押す
- **THEN** 表示が「今日を含む週の月曜日始まり」に戻る (期間長は維持)

## MODIFIED Requirements

### Requirement: 週表示の初期状態

システムは、S01 献立カレンダーを開いたとき、**今日を含む週 (月曜始まり、7 日)** を初期表示 SHALL とする。
初期表示の期間は「1 週」であり、時間帯表示は「夕食のみ」であることをユーザーに示す。ユーザーは期間切替
UI (1 / 2 / 4 週) と前後ナビゲーション (`＜` / `＞` / 「今週」) を画面右上から操作できる。

#### Scenario: 今日を含む週が表示される

- **WHEN** ユーザーが S01 献立カレンダーを開く
- **THEN** 月曜〜日曜の 7 日分の列ヘッダが日付順に表示される
- **AND** 列ヘッダの少なくとも 1 日は「今日」と視覚的に区別できる (例: ハイライト / ラベル)

#### Scenario: 初期の期間・時間帯表示

- **WHEN** ユーザーが S01 を開く
- **THEN** 期間は「1 週」であることが分かる状態で表示される
- **AND** 時間帯表示は「夕食のみ」であり、行は 1 行 (夕食) だけである

### Requirement: 週データ取得の境界

システムは、指定された期間の全 時間帯分の献立エントリを 1 回の取得で SHALL 返す。取得結果は「エントリの
配列」であり、(日付, meal, position) の 3 つ組で並び順が一意に決まる。エントリはレシピ ID とレシピ名の
両方を含み、レシピ名は `recipes` テーブルとの join で解決した表示用の値である。期間は 7 / 14 / 28 日
のいずれか。

#### Scenario: 7 日分のエントリが 1 回で得られる

- **WHEN** 画面が対象週 (periodWeeks=1) の献立を要求する
- **THEN** 応答には対象週の月曜〜日曜のいずれかに属するエントリのみが含まれる
- **AND** 各エントリは日付・meal・position・レシピ ID・レシピ名を持つ

#### Scenario: 指定期間ぶんのエントリが 1 回で得られる

- **WHEN** 画面が対象期間 (7 / 14 / 28 日) の献立を要求する
- **THEN** 応答には対象期間内 (periodStart から periodStart + periodDays 未満) のエントリのみが
  含まれる
- **AND** 各エントリは日付・meal・position・レシピ ID・レシピ名を持つ

#### Scenario: 空の時間帯はエントリを持たない

- **WHEN** ある (日付, meal) に紐づく品が 0 品である
- **THEN** その (日付, meal) に対応するエントリは応答に含まれない
  (「空を表す明示エントリ」は返さない)

#### Scenario: レシピ名は取得時点の最新値

- **WHEN** あるレシピの名称が変更されたあとで、そのレシピを含む週を再取得する
- **THEN** 応答内の該当エントリのレシピ名は変更後の値になる
