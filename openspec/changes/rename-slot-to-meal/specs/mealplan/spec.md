## MODIFIED Requirements

### Requirement: 時間帯表示切替

システムは、朝食 / 昼食 / 夕食 の各時間帯ごとに表示 ON/OFF を切り替えられる UI を画面右上に SHALL 提供する。
デフォルトは夕食だけが ON。ユーザーは必要に応じて朝食・昼食を個別に ON/OFF できる。
選択は表示状態のみに影響し、サーバから受け取るデータ範囲には影響しない。

#### Scenario: 初期状態は夕食のみ ON

- **WHEN** ユーザーが S01 を開く
- **THEN** 夕食チェックボックスだけが ON になっている
- **AND** カレンダーは夕食の 1 行だけ表示される

#### Scenario: 朝食を追加で ON にする

- **WHEN** 夕食のみ ON の状態でユーザーが朝食チェックボックスを ON にする
- **THEN** カレンダーが 2 行 (朝食 / 夕食) に拡張される
- **AND** 昼食は OFF のまま非表示

#### Scenario: 3 つの時間帯すべてを ON にする

- **WHEN** ユーザーが朝食・昼食・夕食のチェックボックスをすべて ON にする
- **THEN** カレンダーが 3 行 (朝食 / 昼食 / 夕食) 表示される

#### Scenario: 夕食を OFF にしても 0 行にはしない

- **WHEN** ユーザーが唯一 ON だった夕食チェックボックスを OFF にしようとする
- **THEN** システムは少なくとも 1 つの時間帯が常に ON であることを保証する
  (最後の 1 つの時間帯は OFF できない)

### Requirement: 時間帯全体のクリア

システムは、時間帯全体を一括削除する UI を SHALL 提供する。実行後、その (日付, meal) は空セルに戻る。

#### Scenario: 時間帯右下 `⋯ → 時間帯全体をクリア` で全削除

- **WHEN** ある (日付, meal) に 2 品ある状態でユーザーが時間帯右下 `⋯ → 時間帯全体をクリア` を選ぶ
- **THEN** その (日付, meal) の全品が削除され、空セルになる

### Requirement: 時間帯内の並び替え

システムは、時間帯内の品の並び順 (position) を、ユーザーが変更できる UI を SHALL 提供する。並び替え結果は
保存され、再表示時にも維持される。ドラッグ&ドロップは要件ではなく、上下ボタン等の代替 UI で満たしてよい。

#### Scenario: 2 品目を上に動かすと 1 品目と入れ替わる

- **WHEN** ある (日付, meal) に「肉じゃが」(position=0)、「みそ汁」(position=1) がある状態でユーザーが
  「みそ汁」の並び替え UI で「上へ」を選ぶ
- **THEN** そのセルは「みそ汁」(position=0)、「肉じゃが」(position=1) の順に並び替えられる

#### Scenario: 並び替えは再起動後も維持される

- **WHEN** 並び替えを保存してからアプリを再起動し、同じ週を表示する
- **THEN** 並び順は並び替え後のまま復元される

### Requirement: 作り置きコピー (時間帯全体)

システムは、時間帯全体 (複数品) の作り置きコピーを SHALL 提供する。ユーザーは時間帯右下 `⋯ → 時間帯全体を
連続 N 日コピー` から日数を選び、次にコピー方法 (「作り置き」= コピー元の全品ごとにコピー先 N 行が
同一の作り置き、「別調理」= 各日ごとに独立した作り置き) を選ぶ。既定は「作り置き」。

#### Scenario: 2 品構成を 3 日分コピーする

- **WHEN** 「月曜・夕」に「肉じゃが」「みそ汁」があり、火〜金・夕が空の状態でユーザーが時間帯右下
  `⋯ → 時間帯全体を連続 3 日` を選ぶ
- **THEN** 「月曜・夕」「火曜・夕」「水曜・夕」の各時間帯に「肉じゃが」「みそ汁」の 2 品が position 順で入る

#### Scenario: 2 品構成を 3 日分コピー (作り置き) するとレシピごとに 3 行が同じ作り置き

- **WHEN** 「月曜・夕」に「肉じゃが」「みそ汁」があり、火〜金・夕が空の状態でユーザーが時間帯右下
  `⋯ → 時間帯全体を連続 3 日 → 作り置き` を選ぶ
- **THEN** 月・火・水曜・夕の「肉じゃが」3 行が 1 つの作り置きに属し、「みそ汁」3 行が別の 1 つの作り置きに属する
- **AND** 「肉じゃが」の作り置きと「みそ汁」の作り置きはそれぞれ異なる枠色で表示される
