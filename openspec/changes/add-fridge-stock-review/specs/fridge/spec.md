## ADDED Requirements

### Requirement: 在庫の見直し

システムは、S05 の在庫のテーブルの上に「見直す」ボタンを SHALL 表示し、押すと在庫の見直しの状態に切り替える。
見直しの状態では、各在庫行の「編集」と「削除」の代わりに「ある」「減った」「ない」の 3 つのボタンを表示する。

- 「ある」：在庫を変えずに、その行を見直し済みにする
- 「減った」：その行の量の欄だけを入力欄に切り替え、今の量を選択した状態でフォーカスする。
  Enter で量を保存してその行を見直し済みにし、Esc で入力欄を閉じて見直し済みにしない。量の検証は在庫の追加と更新と同じ規則に従う
- 「ない」：その行を確認なしで削除し、在庫の削除と同じく「元に戻す」を含む通知を出す。元に戻した行は見直し済みにしない

見直し済みの行は薄く表示する。操作のあとは、表示中の並び順で次の見直し済みでない行の「ある」にフォーカスを移す。
テーブルの上に「見直し済み N / M 件」(M は在庫の全行数) と「見直しを終える」を表示し、「見直しを終える」で通常の表示に戻る。
見直し済みの印は保存せず、見直しを終えたときと S05 を離れたときに消える。
見直しの状態でも、インライン追加行、検索欄、並び替えは使える。常備品の欄は見直しの状態の影響を受けない。

#### Scenario: 見直すと各行に 3 つのボタンが出る

- **GIVEN** 在庫に「玉ねぎ 3 個」と「牛乳 1 本」がある
- **WHEN** ユーザーが S05 で「見直す」を押す
- **THEN** 各在庫行に「ある」「減った」「ない」が表示され、「編集」と「削除」は表示されない
- **AND** テーブルの上に「見直し済み 0 / 2 件」と「見直しを終える」が表示される

#### Scenario: ある を押すと在庫を変えずに見直し済みになる

- **GIVEN** 在庫に「玉ねぎ 3 個」があり、見直しの状態である
- **WHEN** ユーザーが「玉ねぎ」の行の「ある」を押す
- **THEN** 「玉ねぎ」の行は「3 個」のまま薄く表示される
- **AND** 「見直し済み 1 / 2 件」と表示される

#### Scenario: 減った で量を打ち直す

- **GIVEN** 在庫に「玉ねぎ 3 個」があり、見直しの状態である
- **WHEN** ユーザーが「玉ねぎ」の行の「減った」を押し、量に「1」と入れて Enter を押す
- **THEN** 「玉ねぎ」の行は「1 個」になり、薄く表示される
- **AND** S05 を開き直しても「玉ねぎ」の量は「1 個」である

#### Scenario: 減った で量を 0 にすると保存されない

- **GIVEN** 在庫に「玉ねぎ 3 個」があり、見直しの状態である
- **WHEN** ユーザーが「玉ねぎ」の行の「減った」を押し、量に「0」と入れて Enter を押す
- **THEN** 量の欄の下にエラーが表示され、「玉ねぎ」の量は「3 個」のままである

#### Scenario: ない を押すと行が消え、元に戻せる

- **GIVEN** 在庫に「玉ねぎ 3 個」と「牛乳 1 本」があり、見直しの状態である
- **WHEN** ユーザーが「牛乳」の行の「ない」を押す
- **THEN** 確認ダイアログは表示されず、「牛乳」の行は消える
- **AND** 「元に戻す」を含む通知が表示される
- **WHEN** ユーザーが通知の「元に戻す」を押す
- **THEN** 「牛乳 1 本」の行が見直し済みでない状態で戻る

#### Scenario: 操作のあとは次の行にフォーカスが移る

- **GIVEN** 賞味期限の近い順に「牛乳」「玉ねぎ」「にんじん」が並び、見直しの状態である
- **WHEN** ユーザーが「牛乳」の行の「ある」を押す
- **THEN** 「玉ねぎ」の行の「ある」にフォーカスが移る

#### Scenario: 見直しを終えると通常の表示に戻る

- **GIVEN** 在庫に「玉ねぎ 3 個」と「牛乳 1 本」があり、見直しの状態で「玉ねぎ」を見直し済みにしている
- **WHEN** ユーザーが「見直しを終える」を押す
- **THEN** 各行に「編集」と「削除」が表示され、薄く表示される行は無い
- **WHEN** ユーザーがもう一度「見直す」を押す
- **THEN** 「見直し済み 0 / 2 件」と表示される
